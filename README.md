## Key Takeaways

- **Voice is 4x faster than typing** -- 220 WPM vs 45 WPM
- **Spoken prompts are richer** -- you naturally include more context when speaking
- **Flow works everywhere** -- Cursor, VS Code, GitHub, Slack, Notion, any text field
- **AI Auto Edits** clean up filler words, handle corrections, and format automatically
- **Snippets + Dictionary** are the force multipliers -- set them up early
- **The right mic matters** -- wired > wireless > Bluetooth, closer to mouth is better
